# 吻吻花坊手机网页

一个不需要安装依赖的花束展示网站，包含分类筛选、商品详情和咨询文案生成功能。

## 本地查看

在项目目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。

## 替换为真实内容

- 花店名称、电话、地址、营业时间：修改 `index.html`
- 花束名称、价格、分类、照片和介绍：修改 `script.js` 中的 `bouquets`
- 颜色和页面样式：修改 `styles.css`

建议先收集 10 到 20 款真实花束，每款准备：

1. 一张竖版照片
2. 花束名称和编号
3. 参考价格
4. 主要花材
5. 适用场景

## 发布上线

最简单的方式是把代码上传到 GitHub，然后开启 GitHub Pages：

1. 在 GitHub 创建一个公开仓库。
2. 上传这四个文件。
3. 打开仓库的 `Settings` → `Pages`。
4. 在 `Build and deployment` 中选择从 `main` 分支发布。
5. 等待几分钟后，GitHub 会生成可访问的网址。

正式给顾客使用前，建议将远程图片替换成自己拍摄并拥有使用权的花束照片。
